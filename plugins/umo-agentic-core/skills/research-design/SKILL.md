# Research And Design

Start with evidence before choosing an approach.

## Checklist

1. Recall relevant prior decisions and give feedback.
2. Read the authoritative docs or code surface.
3. Identify at least two viable options for non-trivial decisions.
4. Compare trade-offs against the active foundation and module specs.
5. Record the decision in the smallest durable artifact: proposal, ADR, plan, or task note.

Prefer small interfaces and one canonical way per concern. Do not let a functional
plugin redefine core lifecycle semantics.
