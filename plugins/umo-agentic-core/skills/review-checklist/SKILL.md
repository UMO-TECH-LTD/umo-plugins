# Review Checklist

Review behavior before summaries.

## Check

- Does the work satisfy the stated acceptance criteria?
- Are lifecycle, memory, planning, quality, review, and closeout concerns still delegated to core?
- Is there concrete test, lint, typecheck, build, or manual verification evidence?
- Did behavior changes update docs or explain why no docs changed?
- Are generated artifacts stamped with active plugin versions?
- Are residual risks or unrun checks clearly stated?

Findings lead the response. If there are no findings, say that and list remaining
test gaps or residual risk.
