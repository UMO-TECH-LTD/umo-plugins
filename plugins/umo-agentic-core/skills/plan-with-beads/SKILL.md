# Plan With Beads

Planning belongs to `umo-agentic-core`; beads are the default substrate when
available.

## Checklist

1. Identify the user-visible goal.
2. Write acceptance criteria that can be verified.
3. Split independent work into beads only when it reduces risk or parallelizes cleanly.
4. Record dependencies and blockers.
5. Define required quality evidence before implementation starts.
6. Use functional plugin outputs, such as audit findings, as inputs to the core planning flow.

Do not create a separate planning plugin in v1.
