# Memory Workflow

Use memory for durable organizational knowledge.

## Flow

1. Recall broad project/task context at start.
2. Give feedback on every recalled memory.
3. Recall narrowly before decisions, unfamiliar code, or after repeated failure.
4. Remember only durable learnings: decisions, facts, patterns, mistakes, achievements.
5. Include namespace, context, source task, and files when relevant.

Do not write scratch notes to memory. If a memory tool fails, report the failure
and continue with local evidence.
