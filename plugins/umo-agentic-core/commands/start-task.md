description: Start a task with core lifecycle, memory recall, and planning evidence.
---

Start from the active repo root.

1. Recall recent project and task context, then give feedback on every memory.
2. Identify the task goal and acceptance criteria.
3. Check for an existing bead or issue. If none exists and the repo uses beads, create one.
4. Record dependencies, blockers, and required quality evidence.
5. Report the active plugin version and adoption mode if known.

Do not begin implementation until the acceptance criteria and evidence path are clear.
