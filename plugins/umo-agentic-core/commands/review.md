---
description: Review the current change using the core review protocol.
---

Review in this order:

1. Acceptance criteria coverage.
2. Behavioral bugs or regressions.
3. Missing quality evidence.
4. Security, compliance, or architecture risk.
5. Docs and closeout readiness.

Findings come first, ordered by severity. Summaries are secondary. If no issues
are found, say so and list residual risk or test gaps.
