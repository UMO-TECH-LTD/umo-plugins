---
description: Collect and report quality evidence for the current change.
---

Use language, platform, and repo-binding plugins to choose exact commands.

Collect:

- tests run and result;
- lint or formatter result;
- typecheck, compile, or build result;
- docs or spec updates;
- review outcome or remaining risk;
- commands that could not run and why.

In observe mode, report missing evidence without blocking. In enforced mode,
missing required evidence blocks closeout.
